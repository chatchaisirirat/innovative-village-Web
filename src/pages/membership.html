HOW TO JOIN

{ ขั้นตอนการสมัคร }

  1. 1เลือกแพ็กเกจและวันที่ต้องการเริ่มใช้งาน
  2. 2กรอกข้อมูลสมาชิกทีม IV ได้รับแจ้งทาง LINE และ Email ทันที
  3. 3ยืนยัน & ชำระเงินทีมติดต่อกลับพร้อมช่องทางชำระเงิน [รอข้อมูล]
  4. 4ลงทะเบียนเช็คอินผูกบัญชี LINE และลงทะเบียนใบหน้าได้ (ไม่บังคับ) — พร้อมเข้าใช้พื้นที่

FOR MEMBERS

A DAY IN THE VILLAGE

{ ใช้งานพื้นที่อย่างไรเมื่อเป็นสมาชิก }

  1. 01เข้าห้อง Coworkสแกนหน้า หรือเปิด LINE สแกน QR ที่ติดในห้อง
  2. 02เปลี่ยนห้องเช็คอินที่ห้องใหม่ได้เลย ห้องเดิมปิดให้เอง
  3. 03หยิบขนมที่คาเฟ่เช็คอินที่คาเฟ่ก่อนหยิบ ฟรีสำหรับสมาชิก ระบบนับให้เอง
  4. 04กลับบ้านไม่ต้องเช็คเอาท์ ระบบปิดให้เองตอนเวลาปิดทำการ พร้อมส่งสรุปวันนี้ทาง LINE

FAQ

{ คำถามที่พบบ่อย และกติกาการใช้พื้นที่ }

Co-work เปิดกี่โมงถึงกี่โมง?

[วัน / เวลาทำการ] — สมาชิกรายเดือนขอเปิดประตูนอกเวลาได้ผ่านระบบสมาชิก

ลองใช้ก่อนสมัครรายเดือนได้ไหม?

ได้ เลือก Day Pass หรือ นัดดูพื้นที่ ก่อนได้

เช็คอินเข้าพื้นที่อย่างไร?

สแกนหน้าที่เครื่องหน้าห้อง หรือเปิด LINE แล้วสแกน QR ที่ติดในห้อง — ลงทะเบียนใบหน้าได้หลังชำระเงิน (ไม่บังคับ ใช้ QR อย่างเดียวก็ได้)

ออกไปข้างนอกแล้วกลับมาใหม่ต้องทำอย่างไร?

สแกนเช็คอินใหม่ได้เลย ในวันเดียวกันไม่ถูกนับวันเพิ่ม และไม่ต้องเช็คเอาท์ตอนกลับบ้าน

ต่ออายุ / ยกเลิกสมาชิกอย่างไร?

[เงื่อนไขการต่ออายุ การยกเลิก และการคืนเงิน]

กติกาการใช้พื้นที่มีอะไรบ้าง?

[กติกา เช่น เสียงในพื้นที่ การจองโต๊ะ การนำแขกเข้า อาหาร สัตว์เลี้ยง]
